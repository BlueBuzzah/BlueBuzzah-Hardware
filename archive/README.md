# Archived — Deprecated v2 Hardware

These files belong to the **earlier v2 BlueBuzzah hardware** (Adafruit Feather
nRF52840, 4-channel board). They are kept for historical reference only and are
**not** part of a current build.

**Do not use these files for a new build.** The current hardware is BlueBuzzah
v3 — see [`PCB/v3/`](../PCB/v3/) and the
[BlueBuzzah-Hardware wiki](https://github.com/BlueBuzzah/BlueBuzzah-Hardware/wiki).

| File | Description |
| --- | --- |
| `PCB/Bluetooth_4-ch_Buzzah_v2.0_-_2-layer_v4.zip` | v2 PCB Gerber files |
| `PCB/bom.csv` | v2 bill of materials |
| `PCB/positions.csv` | v2 pick-and-place positions |
| `PCB/netlist.ipc` | v2 IPC netlist |
| `Instructions/Blue Buzzah Build Documentation.pdf` | v2 build documentation |
| `3D-Print-Models/Blue Buzzah ABS Case and Tactors rev053125 NMD.stl` | v2 ABS enclosure (does not fit the v3 board) |
